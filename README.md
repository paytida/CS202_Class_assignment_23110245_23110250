# CS202 Class Assignment

This C++ program provides basic arithmetic operations, coin flips, and 6-sided
and 10-sided dice rolls.

## Build

Run `make` or `make all` to compile each source file into an object file and
link the `program` executable. `make` rebuilds only object files whose source
or header dependencies have changed.

Run `make clean` to remove the object files and executable.

## Run

Start the program with `./program` and select an operation from the menu.
Arithmetic operations support addition, subtraction, multiplication, and
division. Division by zero is rejected.
